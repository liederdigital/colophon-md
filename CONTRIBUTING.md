# Contributing

COLOPHON.md is an open convention. The instructions, template, and site are
dedicated to the public domain under [CC0 1.0](LICENSE). By contributing, you
agree to release your contribution the same way.

- **Propose a change as an issue first.** Changes to the convention (the
  instructions, the template, or the rules) start as an
  [issue](https://github.com/liederdigital/colophon-md/issues/new), so they can
  be discussed before anyone writes them up.
- **Small fixes can go straight to a pull request.** Typos, broken links, and
  similar fixes don't need an issue.
- **Add your project.** If your project keeps a COLOPHON.md, open an issue with
  a link to it, and it can be added to the "Who's using it?" list on
  [colophon.md](https://colophon.md).

Pull requests that change the template should change `template.md` and the
template inside `instructions.md` together, and update `COLOPHON.md`, as
described in [`AGENTS.md`](AGENTS.md).
