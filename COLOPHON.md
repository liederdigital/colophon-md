## How the work was done

Ron Stauffer first built the idea as a private agent skill called
"repository-credits," which wrote a `CREDITS.md` file. On October 30, 2026, he
asked Claude whether it was worth sharing and how. Claude looked at existing
approaches; Ron chose the name COLOPHON.md and asked for a byline crediting him
and Lieder Digital. In the same session Claude rewrote the skill as
tool-neutral instructions and a template, built the website, and pushed
everything to this repository as the first commit.
